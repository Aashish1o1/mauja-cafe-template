# Mauja Café - Responsive Café Website Template

A modern, premium and fully responsive café website template built with pure HTML, CSS and JavaScript.

Designed for cafés, coffee shops, bakeries, restaurants and other food businesses that want a clean and modern online presence.

## Live Demo

[View Live Demo](https://mauja-cafe-template.vercel.app/)

## Features

- Modern premium UI/UX
- Fully responsive design
- Mobile-friendly navigation
- Hero section
- About section
- Digital menu
- Image gallery
- Customer reviews
- Location section
- Google Maps integration
- WhatsApp contact button
- Opening hours section
- Smooth scrolling
- Responsive mobile layout
- Easy customization
- Lightweight and fast
- No frameworks required

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
